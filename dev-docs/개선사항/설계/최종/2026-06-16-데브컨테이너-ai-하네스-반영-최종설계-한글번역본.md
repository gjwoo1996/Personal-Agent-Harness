# 최종 구현 설계: 데브컨테이너 AI 하네스 반영

- 작성일: 2026-06-16
- 상태: 최종 구현 설계
- 원본 초본: `dev-docs/개선사항/설계/초본/2026-06-16-데브컨테이너-ai-하네스-반영-계획.md`
- 권위 표준 대상: `standards/devcontainer/devcontainer-standards.md`

> 이 문서는 사람용 한글 번역본이다. 권위본은 영문 문서이며, 충돌 시 영문본을 따른다.

## 구현 목표

`ai-review`에서 선택한 결정을 Personal-Agent-Harness에 반영하되, 배포 템플릿을 스킬 자동 설치
번들로 만들지는 않는다.

구현 결과는 네 가지다.

1. 두 데브컨테이너 모두 Claude Code를 공식 devcontainer Feature로 설치한다.
2. 유지보수 컨테이너는 AI 상태를 리빌드 후에도 보존하고, 매 시작마다 스킬을 멱등 복구한다.
3. 유지보수 컨테이너는 superpowers와 gstack/browse를 설치하며, repo ref 핀 옵션을 제공한다.
4. 배포 템플릿에는 Claude Feature 전환, 선택형 방화벽 파일, 스킬 설치 표준 문서만 포함한다.

## 제외 범위

- 새 규칙 도메인을 추가하지 않는다.
- `templates/devcontainer/`에 superpowers 또는 gstack 자동 설치 스크립트를 넣지 않는다.
- 생성된 타깃 프로젝트 사본인 `docs/devcontainer/`는 수정하지 않는다. 원본 `standards/`만 수정한다.
- 이 구현 과정에서 `main` merge 또는 push를 하지 않는다.

## 파일별 변경 명세

### 1. 유지보수 데브컨테이너

`.devcontainer/devcontainer.json` 수정:

- Feature 추가:

```json
"ghcr.io/anthropics/devcontainer-features/claude-code:1.0": {}
```

- 기존 GitHub CLI Feature는 유지한다.
- `customizations.vscode.extensions`에서 `anthropic.claude-code`를 제거한다.
- `openai.chatgpt`는 유지한다.

`.devcontainer/Dockerfile` 수정:

- `ARG CLAUDE_CODE_VERSION`을 제거한다.
- `npm install -g`에서 `@anthropic-ai/claude-code@${CLAUDE_CODE_VERSION}`를 제거한다.
- 빌드 단계의 `claude --version`을 제거한다.
- `ARG CODEX_CLI_VERSION`은 유지한다.
- `@openai/codex@${CODEX_CLI_VERSION}`와 `codex --version`은 유지한다.
- gstack/browse 헬스체크를 위해 apt 패키지에 `chromium`을 추가한다.

```dockerfile
RUN apt-get update \
    && apt-get install -y --no-install-recommends ca-certificates curl jq chromium \
    && rm -rf /var/lib/apt/lists/*
```

`.devcontainer/docker-compose.dev.yml` 수정:

- build arg `CLAUDE_CODE_VERSION`을 제거한다.
- build arg `CODEX_CLI_VERSION`은 유지한다.
- named volume `pah-claude-json`을 추가한다.
- `/home/vscode/.ai-state/claude`에 마운트한다.
- 유지보수 컨테이너 방화벽을 위해 capability를 추가한다.

```yaml
cap_add:
  - NET_ADMIN
  - NET_RAW
```

`.devcontainer/.env.example`과 `.devcontainer/commands/initializeCommand.sh` 수정:

- `CLAUDE_CODE_VERSION`을 제거한다.
- `CODEX_CLI_VERSION`은 유지한다.
- 생성되는 `.devcontainer/.env`에도 `CLAUDE_CODE_VERSION`이 없어야 한다.

`.devcontainer/versions.env` 추가:

```bash
BUN_VERSION=1.2.17
SUPERPOWERS_REPO=https://github.com/obra/superpowers.git
SUPERPOWERS_REF=
SUPERPOWERS_MARKETPLACE=obra/superpowers-marketplace
GSTACK_REPO=https://github.com/briangwaltney/gstack.git
GSTACK_REF=
```

규칙:

- 빈 `*_REF`는 기본 브랜치 HEAD를 사용한다는 뜻이다.
- 값이 있는 `*_REF`는 clone/fetch 뒤 해당 tag, branch, SHA를 정확히 checkout한다.
- `versions.env`는 커밋되는 기본값 파일이며 secret 파일이 아니다.

`.devcontainer/commands/install-superpowers.sh`를
`.devcontainer/commands/ensure-ai-skills.sh`로 이름 변경한다.

새 스크립트는 `versions.env`를 source하고 다음 단위를 구현한다.

- `ensure_ai_volume_permissions`: 기존 `ensure-ai-volume-permissions.sh`를 호출한다.
- `ensure_bun`: `BUN_VERSION`의 Bun을 설치 또는 검증한다. Bun 설치가 불가능하면 경고 후 gstack 설정을 건너뛴다.
- `ensure_repo <url> <path> <ref>`: 없으면 clone, 있으면 fetch, `ref`가 있으면 checkout한다.
- `ensure_claude_superpowers`: `SUPERPOWERS_MARKETPLACE`를 사용한다. `claude`가 없으면 경고 후 건너뛴다.
- `ensure_codex_superpowers`: 현재 신뢰 가능한 symlink 방식을 유지한다.
`~/.agents/skills/superpowers -> ~/.codex/superpowers/skills`; Codex plugin은 가능할 때만 시도한다.
- `ensure_codex_multi_agent`: 현재 `[features] multi_agent = true` 동작을 보존한다.
- `ensure_gstack`: `GSTACK_REPO`를 `~/.codex/gstack`에 clone/fetch하고, `GSTACK_REF`가 있으면 checkout한 뒤 실행한다.

```bash
bun install
bun run setup --host claude
bun run setup --host codex
```

- `verify_browse_chromium`: 작은 Playwright/Chromium launch 검사를 실행한다. 실패해도 컨테이너 전체를 실패시키지 않고 경고한다.

실패 정책:

- `claude` 없음, `codex` 없음, 일시적인 marketplace 불가, gstack 브라우저 헬스체크 실패는 `WARN:`을 출력하고 계속한다.
- 쉘 문법 오류, 필수 스크립트 누락, 권한 복구 실패는 즉시 실패한다.

`.devcontainer/commands/ensure-ai-volume-permissions.sh` 수정:

- ownership 복구 대상에 `/home/vscode/.ai-state`를 포함한다.

`.devcontainer/commands/post-create.sh` 수정:

- AI 버전 출력 전에 Claude 파일 상태를 보존한다.

```bash
mkdir -p /home/vscode/.ai-state/claude
if [ -e /home/vscode/.claude.json ] && [ ! -L /home/vscode/.claude.json ]; then
  cp /home/vscode/.claude.json /home/vscode/.ai-state/claude/.claude.json
fi
touch /home/vscode/.ai-state/claude/.claude.json
ln -sfn /home/vscode/.ai-state/claude/.claude.json /home/vscode/.claude.json
```

- `install-superpowers.sh` 호출을 `ensure-ai-skills.sh` 호출로 바꾼다.
- 상태 출력에 gstack/browse 헬스체크 결과를 포함한다.

`.devcontainer/commands/post-start.sh` 수정:

- echo만 하던 스크립트를 아래 흐름으로 바꾼다.

```bash
#!/usr/bin/env bash
set -euo pipefail

SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
"$SCRIPT_DIR/ensure-ai-skills.sh"
"$SCRIPT_DIR/init-firewall.sh"
```

`.devcontainer/commands/init-firewall.sh` 추가:

- 멱등이어야 한다.
- `iptables` 또는 `ipset`이 없으면 `WARN:`을 출력하고 exit 0 한다.
- loopback, established connection, DNS, GitHub, npm registry, Anthropic endpoint, OpenAI endpoint,
Bun download, Playwright/Chromium download를 허용한다.
- 최초 설정에 outbound package/browser download가 필요하므로 `ensure-ai-skills.sh` 이후에만 적용한다.

`.devcontainer/README.md` 수정:

- Claude npm pin 설치 설명을 공식 Feature 설명으로 교체한다.
- `.claude`, `.claude.json`, `.codex` named volume 보존을 문서화한다.
- `ensure-ai-skills.sh`, `versions.env`, gstack/browse, 기본 ON 유지보수 방화벽을 문서화한다.
- troubleshooting 명령을 `ensure-ai-skills.sh` 기준으로 갱신한다.

### 2. 데브컨테이너 표준 문서

먼저 `standards/devcontainer/devcontainer-standards.md`를 수정하고,
`standards/devcontainer/devcontainer-standards.ko.md`를 동기화한다.

필수 의미 변경:

- Final Consensus:
  - "AI CLI는 Dockerfile에서 명시적으로 고정된 버전으로 설치"를
  "공식 devcontainer Feature가 있는 AI CLI는 Feature를 사용하고, 없으면 Dockerfile에서 핀 버전으로 설치"로 바꾼다.
- Version Pinning:
  - 필수 pin 목록에서 `CLAUDE_CODE_VERSION`을 제거한다.
  - `CODEX_CLI_VERSION`은 유지한다.
  - Claude Code는 공식 Feature의 update channel을 기본으로 사용한다고 명시한다.
  - 프로젝트가 npm-pinned Claude Code를 선택하면 Claude autoupdater도 비활성화하고 예외를 문서화해야 한다.
- AI CLI Installation:
  - Claude Code 기본값은 공식 Feature다.
  - Codex 기본값은 `CODEX_CLI_VERSION`을 사용하는 Dockerfile npm 설치다.
  - Claude를 Feature와 Dockerfile 양쪽에서 동시에 설치하는 것을 명시적으로 금지한다.
- Lifecycle Commands:
  - AI 상태가 volume-backed일 때 `post-start.sh`가 가벼운 멱등 AI 스킬 복구를 실행할 수 있다고 명시한다.
- `AI Skill Setup (superpowers / gstack)` 섹션 추가:
  - 배포 템플릿은 이 설정을 문서화하되, 프로젝트가 opt-in하지 않는 한 스킬을 자동 설치하지 않는다고 설명한다.
  - 필수 원칙을 정의한다: named-volume 상태, 멱등 post-start 복구, 선택형 repo ref pin, graceful degradation.
  - 유지보수 `.devcontainer/commands/ensure-ai-skills.sh`를 참조 구현으로 둔다.

표준 경로나 managed block 문구를 바꿀 필요가 없다면 `templates/stubs/agent-blocks/devcontainer.md`는 수정하지 않는다.
기존 stub은 이미 agent가 `docs/devcontainer/devcontainer-standards.md`를 읽도록 안내한다.

### 3. 배포 데브컨테이너 템플릿

`templates/devcontainer/devcontainer.json` 수정:

- `ghcr.io/anthropics/devcontainer-features/claude-code:1.0`을 추가한다.
- VS Code extensions에서 `anthropic.claude-code`를 제거한다.
- GitHub CLI Feature와 `openai.chatgpt`는 유지한다.

`templates/devcontainer/Dockerfile` 수정:

- `ARG CLAUDE_CODE_VERSION`을 제거한다.
- `@anthropic-ai/claude-code@${CLAUDE_CODE_VERSION}`와 `claude --version`을 제거한다.
- `ARG CODEX_CLI_VERSION`, Codex npm install, `codex --version`은 유지한다.

`templates/devcontainer/docker-compose.dev.yml` 수정:

- build arg `CLAUDE_CODE_VERSION`을 제거한다.
- build arg `CODEX_CLI_VERSION`은 유지한다.
- 기존 named volume은 유지한다.
  - `claude-config:/home/vscode/.claude`
  - `claude-json:/home/vscode/.ai-state/claude`
  - `codex-config:/home/vscode/.codex`

`templates/devcontainer/.env.example`과
`templates/devcontainer/commands/initializeCommand.sh` 수정:

- `CLAUDE_CODE_VERSION`을 제거한다.
- `CODEX_CLI_VERSION`은 유지한다.
- 필수 env 오류 메시지는 `CODEX_CLI_VERSION`만 언급해야 한다.
- 생성되는 `.devcontainer/.env`에는 `CLAUDE_CODE_VERSION`이 없어야 한다.

`templates/devcontainer/commands/init-firewall.sh` 추가:

- 유지보수 방화벽과 같은 형태의 스크립트지만 `postCreateCommand` 또는 `postStartCommand`에 연결하지 않는다.
- 타깃 프로젝트가 선택적으로 켤 수 있는 예시 파일이다.

`templates/devcontainer/README.md` 수정:

- Claude Code가 공식 Feature로 제공된다고 문서화한다.
- AI state storage 섹션은 유지한다.
- 선택형 superpowers/gstack 설정은 `docs/devcontainer/devcontainer-standards.md`를 보라고 짧게 안내한다.
- `commands/init-firewall.sh` opt-in 안내를 추가한다.

배포 템플릿에는 `ensure-ai-skills.sh`, `versions.env`, Bun, superpowers clone 로직, gstack clone 로직,
post-start 스킬 복구를 추가하지 않는다.

### 4. 테스트

`tests/test_pah.sh` scaffold assertion 수정:

- `CLAUDE_CODE_VERSION=2.1.170` assertion을 제거한다.
- `CODEX_CLI_VERSION=0.139.0` assertion은 유지한다.
- 설치된 scaffold 파일에 대해 다음 assertion을 추가한다.
  - `ghcr.io/anthropics/devcontainer-features/claude-code:1.0`
  - `@anthropic-ai/claude-code`가 없음
  - `CLAUDE_CODE_VERSION`이 없음
  - `@openai/codex@${CODEX_CLI_VERSION}`
  - `.devcontainer/commands/init-firewall.sh`가 존재함
- 기존 named-volume assertion은 유지한다.

나중에 유지보수 데브컨테이너 파일을 테스트 범위에 넣는다면 다음을 검증한다.

- `.devcontainer/docker-compose.dev.yml`이 `pah-claude-json:/home/vscode/.ai-state/claude`를 마운트한다.
- `.devcontainer/commands/post-start.sh`가 `ensure-ai-skills.sh`를 `init-firewall.sh`보다 먼저 호출한다.
- `.devcontainer/commands/install-superpowers.sh`가 더 이상 존재하지 않는다.

## 필수 검증

구현 후 저장소 루트에서 실행한다.

```bash
bash tests/test_pah.sh
git diff --check
```

Docker 사용 가능 환경에서는 정적 devcontainer config도 확인한다.

```bash
docker compose -f .devcontainer/docker-compose.dev.yml config
```

유지보수 컨테이너 수동 리빌드 검증:

```bash
claude --version
codex --version
test -L ~/.claude.json
claude plugin list | grep superpowers
test -e ~/.agents/skills/superpowers
test -d ~/.codex/gstack
```

gstack/browse는 `ensure-ai-skills.sh`에 구현된 헬스체크를 사용한다. Chromium launch가 성공하거나,
실패한 명령이 포함된 명확한 `WARN:`을 출력해야 한다.
