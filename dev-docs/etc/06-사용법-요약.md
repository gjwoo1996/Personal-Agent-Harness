# 06. 사용법 요약 (변경 전 / 후)

## 변경 전 (문제 있던 방식)

```bash
# 대상 프로젝트 루트
git clone <url> Personal-Agent-Harness
./Personal-Agent-Harness/setup.sh
./Personal-Agent-Harness/update.sh
```

**프로젝트 결과:**

```text
my-project/
├── .git/
├── docs/ ...              ← 복사됨 (필요)
├── .harness/manifest.json ← 필요
└── Personal-Agent-Harness/  ← 전체 harness + .git (불필요·문제)
    └── .git/              ← 중첩 git
```

---

## 중간 단계 (Approach C — PAH_HOME)

```bash
git clone <url> ~/.local/share/personal-agent-harness
~/.local/share/personal-agent-harness/bootstrap.sh ~/projects/my-app
~/.local/share/personal-agent-harness/update.sh ~/projects/my-app
```

**프로젝트 결과:**

```text
my-project/
├── docs/ ...
└── .harness/manifest.json
(Personal-Agent-Harness/ 없음)
```

**단점:** 경로 기억, 명령어 김

---

## 변경 후 (현재 — GitHub npx)

```bash
cd ~/projects/my-app
npx --yes github:gjwoo1996/Personal-Agent-Harness init .
npx --yes github:gjwoo1996/Personal-Agent-Harness update .
npx --yes github:gjwoo1996/Personal-Agent-Harness verify .
npx --yes github:gjwoo1996/Personal-Agent-Harness status .
```

**프로젝트 결과:** 중간 단계와 동일 (규칙만 복사)

**하네스 도구 위치:** npx가 GitHub 저장소에서 받아 사용하는 캐시(프로젝트 밖)

**환경:** Node.js 24 LTS 권장 (최소 22), bash 3.2+, jq 권장

---

## git checkout (하네스 개발자)

하네스 **소스 수정** 또는 로컬 checkout 사용:

```bash
git clone https://github.com/gjwoo1996/Personal-Agent-Harness.git
cd Personal-Agent-Harness
bash tests/test_pah.sh
./bin/pah init /path/to/target
```

monorepo에서 harness 개발:

```bash
./Personal-Agent-Harness/bin/pah install . --components harness-dev
```

## in-project clone 마이그레이션

이미 프로젝트 안에 clone해 둔 경우:

```bash
npx --yes github:gjwoo1996/Personal-Agent-Harness init . --clean-nested
```

또는 git checkout:

```bash
~/.local/share/personal-agent-harness/bootstrap.sh . --clean-nested
```

## 대상 프로젝트에서 커밋할 파일

**커밋:**

- `docs/devcontainer/`, `docs/git-workflow/`
- `.cursor/rules/*.mdc`
- `AGENTS.md`, `CLAUDE.md`
- `.harness/manifest.json`
- (선택) `.devcontainer/`, `.gitignore` (pah managed block)

**커밋하지 않음:**

- `Personal-Agent-Harness/`
- `.harness/backups/`
- `node_modules` (규칙이 여기 들어가지 않음)

## 버전·업데이트 추적

| 질문 | 확인 방법 |
|------|-----------|
| 프로젝트에 뭐가 설치됐나? | `.harness/manifest.json` → `harness_version` |
| CLI보다 오래됐나? | `pah status .` → `update available` |
| 어떻게 업데이트? | `npx --yes github:gjwoo1996/Personal-Agent-Harness update .` |
