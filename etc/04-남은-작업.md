## P2 — UX 개선 (선택)

### 8. 셸 alias 가이드

`~/.bashrc`:

```bash
alias pah-init='npx personal-agent-harness init'
alias pah-up='npx personal-agent-harness@latest update'
```

### 9. GitHub Actions release workflow

- tag push → `npm test` + `npm publish`
- `NPM_TOKEN` 시크릿

### 10. `pah status` 개선

- publish된 npm 최신 버전과 비교 (`npm view personal-agent-harness version`)
- 네트워크 필요, 오프라인 fallback

### 11. devDependency 워크플로우

Node 프로젝트용:

```json
"devDependencies": { "personal-agent-harness": "0.3.1" },
"scripts": { "harness:init": "pah init ." }
```

문서화만으로도 가능.
